# Взаимодействие с поисковыми запросами

## Анализ поискового запроса

Для работы с поисковыми запросами можно использовать сервис
[dadata.ru](https://dadata.ru/api/clean/vehicle/).
Подразумевается получение от пользователя поисковой строки и отправка запроса
на API dadata, который в свою очередь вернёт разобранный запрос,
в дальнейшем можно будет использовать для взаимодействия внутри
серверной части.

**Пример**

```go
package main

import (
	"context"
	dadata "github.com/ekomobile/dadata/v2"
)

func main() {
	api := dadata.NewCleanApi()
	query := "форд фокус"
	result, err := api.Vehicle(context.Background(), query)
}
```

И получаем стандартизированный ответ

```json
[
  {
    "source": "форд фокус",
    "result": "FORD FOCUS",
    "brand": "FORD",
    "model": "FOCUS",
    "qc": 0
  }
]
```

**Обозначения ответа:**

| Название | Тип         | Описание                     |
|----------|-------------|------------------------------|
| source   | string(100) | Исходное значение            |
| result   | string(100) | Стандартизированное значение |
| brand    | string(50)  | Марка                        |
| model    | string(50)  | Модель                       |
| qc       | number      | Код проверки                 |

**Коды проверки:**

| код qc | Описание                                                     | Нужно проверить вручную? |
|--------|--------------------------------------------------------------|--------------------------|
| 0      | Уверенно распознаны марка и модель                           | нет                      |
| 3      | Уверенно распознана марка, модели нет                        | нет                      |
| 2      | Исходное значение пустое или заведомо мусорное               | нет                      |
| 1      | Исходное значение распознано с допущениями или не распознано | да                       |

### Ограничение

- В запросе только один автомобиль
- Максимальная частота запросов - 20 в секунду
- Максимальная частота создания новых соединений - 60 в минуту с одного IP-адреса
