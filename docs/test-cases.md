# Тест-кейсы

## Обозначения

- `TC-*` — идентификатор тест-кейса
- `FR-*` — связанное функциональное требование
- `NFR-*` — связанное нефункциональное требование

## TC-03 Успешное создание аренды

- Предусловия:
1. Пользователь авторизован.
2. Автомобиль существует и свободен в выбранный период.
- Шаги:
1. Отправить запрос на создание аренды с валидными датами.
2. Получить ответ API.
- Ожидаемый результат:
1. Возвращается `201 Created`.
2. В ответе содержится созданная аренда с корректными датами и `car_id`.

## TC-04 Запрет двойной аренды

- Предусловия:
1. Для авто уже существует аренда на период `A-B`.
- Шаги:
1. Отправить новый запрос на аренду того же авто на пересекающийся период.
- Ожидаемый результат:
1. Возвращается ошибка бизнес-валидации.
2. Вторая аренда не создается.

## TC-08 Поиск в агрегаторе и импорт авто

- Предусловия:
1. Админ авторизован.
2. Сервис агрегатора доступен.
- Шаги:
1. Выполнить запрос поиска в агрегатор.
2. Выбрать один из результатов.
3. Выполнить импорт в Morent.
- Ожидаемый результат:
1. API возвращает успешный ответ.
2. Импортированное авто появляется в каталоге.

## TC-09 Недоступный агрегатор

- Предусловия:
1. Админ авторизован.
2. Агрегатор недоступен.
- Шаги:
1. Выполнить запрос поиска в агрегатор.
- Ожидаемый результат:
1. Возвращается контролируемая ошибка (`5xx/Service Unavailable`).
2. Основной backend Morent остается работоспособным.

## TC-12 Проверка ролей для админ-операций

- Предусловия:
1. Есть токен обычного пользователя.
- Шаги:
1. Отправить запрос на admin endpoint с user-токеном.
- Ожидаемый результат:
1. Возвращается `403 Forbidden` (или `404 Not Founded` чтобы не 'палить' админ-панель)
2. Доступ к админ панели закрыт


## TC-20 Импорт авто из агрегатора в Morent

- Предусловия:
1. Админ Morent авторизован.
2. `car-aggregator` доступен.
- Шаги:
1. Выполнить поиск авто в агрегаторе из админки Morent.
2. Выбрать найденный авто-оффер.
3. Выполнить импорт в каталог Morent.
- Ожидаемый результат:
1. Импорт завершается успешно.
2. Автомобиль появляется в каталоге Morent.
3. Повторный поиск в агрегаторе не показывает уже забранный оффер.
